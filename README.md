# Desafio Aula 3 - Java ☕

Projeto desenvolvido durante o curso **Capacita I-ReDe** com o objetivo de praticar conceitos fundamentais da linguagem Java, incluindo:

- Estruturas de repetição (`for` e `while`)
- Estruturas de decisão (`if/else` e `switch case`)
- Arrays
- Métodos
- Entrada de dados com `Scanner`
- Validação de dados
- Organização de código orientada a objetos

---

# 📚 Desafios Desenvolvidos

O projeto contém 3 desafios propostos durante a aula.

---

# ✅ Desafio 1 — Média do Aluno

Programa que:

- Recebe 3 notas do aluno
- Armazena as notas em um array
- Calcula a média
- Exibe o resultado na tela

## Exemplo de entrada

```text
8,5
7,0
6,1
```

## Exemplo de saída

```text
Média: 7.2
```

---

# ✅ Desafio 2 — Status do Aluno

Evolução do desafio anterior.

Além de calcular a média, o programa:

- Verifica se o aluno foi aprovado ou reprovado
- Considera média mínima igual a `7.0`

## Exemplo de saída

```text
Média: 7.2
Status: Aprovado
```

---

# ✅ Desafio 3 — Calculadora de Média Genérica

Versão dinâmica do programa.

Agora o usuário pode:

- Escolher quantas notas deseja inserir
- Definir a média mínima para aprovação

## Exemplo de entrada

```text
4
5
6
4,5
6,5
6,0
```

## Exemplo de saída

```text
Média: 5.5
Status: Reprovado
```

- ✅ Separação dos desafios em métodos

- ✅ Código comentado para estudo

---

# 📌 Validação de Dados

O sistema aceita apenas notas entre:

```text
0 até 10
```

Caso o usuário digite valores inválidos, o programa solicita uma nova entrada.
